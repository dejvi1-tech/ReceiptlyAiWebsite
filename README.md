# Receiptly AI — Website

Landing page + Privacy, Terms and Support pages for the Receiptly AI iOS app.
German by default, English available. Built with Vite + React.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

Hosted on Netlify (publish directory: `dist`). Routes fall back to `index.html` via `public/_redirects`.

Edit `src/config.js` for the domain, contact email and App Store link.
